# FloV:MP — установка сервера

Актуальная версия — **1.0.18 Beta** ([что нового](../../releases/latest)).

## Как установить

1. Скачайте [`flovmp-setup.zip`](flovmp-setup.zip) (кнопка **Download raw file** справа вверху).
2. Распакуйте архив куда удобно — например, на Рабочий стол. В нём два файла:
   - `FloVMP-Setup.cmd` — установка и обновление сервера (Windows);
   - `ИНСТРУКЦИЯ.txt` — полная инструкция: Windows, Linux, обновление, ошибки.
3. Двойной щелчок по `FloVMP-Setup.cmd` → папка сервера → ключ лицензии.

Обновление — тот же `FloVMP-Setup.cmd`: он найдёт установленный сервер и обновит его.
Linux (Ubuntu / Debian) — раздел 4 в `ИНСТРУКЦИЯ.txt`.

Нужен **ключ лицензии** (выдаётся при покупке, вид `FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX`).

## Почему в архиве так мало

Сервер, установщик и обновления выдаёт сервер раздачи FloV:MP **только по действующему
ключу лицензии** и только по HTTPS. Всё, что скачивается, проверяется подписью FloV:MP и
SHA-256 — подменённый файл не запустится. Ключ хранится только в папке установленного
сервера; архив и скрипт его не запоминают.

## Если сервер стоит с версии 1.0.17 или раньше

Прежние установщики брали пакеты с GitHub, а здесь их больше нет. Один раз обновитесь новым
`FloVMP-Setup.cmd` (укажите папку уже установленного сервера — он обновится, а файлы старого
установщика с ключом будут убраны). На Linux — командой из раздела 4 `ИНСТРУКЦИЯ.txt`.
